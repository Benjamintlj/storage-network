# Concepts

| Term      | Definition                                                     |
| --------- | -------------------------------------------------------------- |
| Object    | Sequence of bytes with an identifier.                          |
| Filename  | A human facing label that may change.                          |
| Invarient | A property that must always remain true across all operations. |

After storing an object, a later read must return all the bytes. It must never return a partial object as if it were complete.

Identifiers cannot be reused. It this happens then we should return a conflict.


# Requirements

Create a persistent storage system.

#### Storage layer
```go
func Open(dir string) (*DiskStore, error)
func (s *DiskStore) Put(id string, body []byte) error
func (s *DiskStore) Get(id string) ([]byte, error)
```
- Write persistently  
- Duplicate write (same bytes & id), are successful, one object  
- Different bytes same identifier, conflict  
- Unknown identifier, unknown  
- Do not allow writes over the size of 8MiB, this memory must be pre-allocated  
  
- Empty object, binary object, text  
- Stop the program completely, objects should still be readable  
- Block ids that may act as paths such as `../`


#### Cmd
Implement these two commands
`put --data-dir DIR ID INPUT`
`get --data-dir DIR ID OUTPUT`
